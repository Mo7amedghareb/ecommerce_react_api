# React E-Commerce App

A responsive e-commerce web application built with React, Bootstrap, and REST APIs. The application provides a modern shopping experience with product browsing, category filtering, search, and shopping cart functionality.

## Features

- Browse Products
- Product Details
- Category Filtering
- Product Search
- Shopping Cart
- Responsive Design
- REST API Integration
- Dynamic Routing

## Technologies

### Frontend
- React
- JavaScript (ES6)
- Bootstrap

### APIs
- REST API

## Purpose

This project was developed to practice building modern single-page applications (SPA) using React, component-based architecture, API integration, and responsive UI development.
